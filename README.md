# What's included in this mod? 

### So far, Galactic Neighbors is in its beta phase. It has 2 stars, 9 planets, and 6 moons. 

> All bodies (Except gas giants) Feature full parallax, scatterer, and Volumetric clouds support.

|Stars|
|------|
|Alpha Kerbonis|
|Beta Kerbonis|

|Alpha Kerbonis|Moons   |Beta Kerbonis| Moons|
|--------------|--------|-------------|------|
|Gale          |Breeze  |Dol and Mraw |Eur and Bep|
|Oasis         |None    |Bahlite      |Ring system|
|Sage          |None    |
|Erion         |Hop     |
|Harpy         |Arrow   |
|Aurae         |Baj     |

> Note that Baj is broken. You will explode while trying to land on it.

  # After extracting, it should bring you to a new file explorer window. Now drag the GalacticNeighbors folder into Gamedata. Make sure there is only 1 GalacticNeighbors folder or the mod WILL NOT work
